# v0.2 工作阶段收尾记录

2026-09-30，按用户明确决定停止 v0.2 性能专项的继续开发，转入 v0.3 功能规划。
这是**带已知限制的范围收尾**，不是宣称
[`PERFORMANCE_OPTIMIZATION_V0.2.md`](PERFORMANCE_OPTIMIZATION_V0.2.md) 第 10 节的
所有原始发布验收条件已达成；原文中未勾选项保持未勾选。不创建发布 tag，
也不把实验数据表述为通用生产性能承诺。

## 已交付与证据

- v0.2 的四类吞吐方向目标已在专项文档中勾选；现有核心保持 Arrow 语义、
  不可变 Segment、checksum 和 v0.1 文件可读性。Reader 默认单线程，内部并行
  为显式 opt-in、有界调度；多个独立 Scan 可并发。
- [`BENCHMARK_V2.md`](../bench/BENCHMARK_V2.md) 保存 Sniffer 与 Parquet
  的同条件对照、压缩/解压、资源指标及实验限制。最新跨六种分布的
  Row Group × 选择率 × 投影 × 缓存旁路矩阵有 1,536 个 case、每个 7 次重复；
  [汇总 TSV](../bench/results/V0.2_DISTRIBUTION_MATRIX_2026-09-30.tsv) 和
  原始 JSONL 均已入库。
- 收尾前最近一次 Release 全量 CTest 为 99/99；Reader-memory benchmark
  的 ASan/UBSan smoke 通过。此前并发路径做过 TSan 测试；这些记录不能
  代替每一项最终非回归门槛的独立签收。

## 接受的限制与后续候选

1. **物理 cold-cache 未验证。** 21.12 GB 语料在 16 GiB 机器上的首次读取，
   以及 `F_NOCACHE` 对照均已记录，但没有目标块缓存状态或设备级实际读取量
   证据；不把近似冷读记作严格 cold-cache 验收。
2. **并发发布矩阵未闭环。** 对象级契约、正确性、TSan 和代表性 1/2/4/8
   worker/请求对照已有证据，但跨数据分布的多查询资源预算、错误/取消边界
   及可选并行写入没有完成全覆盖。默认串行 fallback 保留。
3. **完整发布级回归报告未签收。** 原第 2 节全部非回归门槛、每项性能结论
   的 profiler 归因，以及与 v0.1 完全同 runner/同参数的全矩阵 A/B 尚缺统一
   验收；历史数字不可直接视为版本间加速比。
4. 其它未勾选的 P0/P1 微优化和 SIMD/新编码评估属于候选工作，不因本次
   收尾而视为完成，也不自动进入 v0.3。v0.3 应另定功能目标和验收范围。

上述取舍只改变**项目阶段是否继续投入**，不修改 `DESIGN.md` 的文件格式、
安全性或 API 语义。未来若要声明 v0.2 满足原发布验收，须补证据或明确修订
验收定义；本记录本身不是这种声明。
